# 系统提示词服务

## 先弄懂这门课在讲什么

你发给 AI 的问题前面，程序还会先放一段“给 AI 的说明”。这段说明叫**系统提示词**。它可以告诉 AI 要扮演谁、回答时遵守什么规则。

系统提示词通常由几小段文字组成。比如：

> 你是一个助手。
> 回答时请使用短句。

这门课要讲的是：这些小段文字从哪里来、怎样决定先后、怎样只对某个会话生效，最后又怎样交给模型。

先记住四个词：

| 代码里的词 | 用大白话说 |
|---|---|
| `section`（片段） | 系统提示词中的一小段文字 |
| 注册 | 把一段文字加入系统的清单 |
| `scope`（作用域） | 这段文字对哪些会话生效；根作用域是大家共用的区域，嵌套作用域是某个会话自己的区域 |
| `order`（顺序） | 决定这些文字按什么顺序排列的数字 |

**不用从头读完整个代码文件。** 代码面板展示的是原项目作者写的代码，可能很长；每一阶段会自动跳到重点。先读左侧的说明，再看代码里被标出的几行即可。

左边展示原始代码；点“运行此阶段”时，实验台会执行原项目发布的程序包（npm 包）。两者属于同一个版本。你可以先把它理解成“看原始做法，同时试用对应版本的成品”，不需要了解 npm 的工作方式。

## 00 服务和设置

**这一步在做什么？** `SystemPrompt` 是一段专门管理系统提示词的程序。它启动时会读取设置，并先放入两段默认文字：一段告诉模型它是 Harness 提供的 AI 助手，另一段是应用配置里的角色说明。

`Config` 是这些设置的名字和值。例如，当前示例把 `personaPrefix`（角色说明）设为“你是一个助手”，所以每次模型请求都会带上这句话。你不需要理解配置系统的细节；只要知道这里是在准备默认文字。

**动手看看：** 点击“运行此阶段”，再打开右侧“状态与数据”。在“模型请求的 system 文本”里找 Harness 身份说明和“你是一个助手”。这里的 `system` 就是发给模型的系统提示词。

## 01 把一段话加入系统提示词

**这一步在做什么？** 插件可以调用 `section()` 把一小段文字加入系统提示词。可以把它想成往清单里加一张卡片：卡片有名字、先后顺序和正文。

名字用来区分卡片；同一个区域里不能有两张同名卡片。`order` 是摆放顺序的数字：数字小的排前面。`section()` 还会交回一项清理操作；拥有这张卡片的插件卸载时，系统会把它移走。

**动手看看：** 运行本阶段。场景会先发一条没有额外卡片的请求，再挂载贡献插件并发请求，最后卸载插件再请求。打开“状态与数据”，比较几次请求的 system 文本：挂载后会多出“回答时使用短句”，卸载后它会消失。

## 02 不同会话看到不同说明

**这一步在做什么？** `scope`（作用域）就是一块“适用范围”。根作用域里的文字大家都能看到；某个嵌套作用域里的文字只影响被分到那块区域的会话。

如果内外两块区域有一段同名文字，内层会优先使用自己的版本，不会把两段都放进去。其他会话仍然使用外层版本。

**动手看看：** 运行本阶段。场景会先挂载根作用域和嵌套作用域的两个贡献插件，它们注册了同名卡片，但正文不同。随后分别发起两次请求：根作用域看到“回答时使用短句”，嵌套会话看到“回答时使用英文”。这就是局部版本只覆盖自己范围内内容的效果。

## 03 还能加入哪些信息

**这一步只看代码，不会单独运行。** 除了固定文字，服务还允许插件登记三类东西：

- `context()`：每次请求前可以更新的背景信息，例如当前环境或工作目录。
- `variable()`：给提示词里的空位提供值。比如模板写着 `你好，{{name}}`，变量 `name` 的值是“小林”，拼好后就是“你好，小林”。
- `tools()`：告诉模型有哪些工具可以调用，以及每个工具需要什么参数。

代码里的 `interpolate()` 就像填空步骤：它会找到 `{{name}}` 这样的空位并填入对应的值；找不到值时会报错。当前课程没有专门运行这些动态信息，所以这里只解释代码，不把它说成已经在场景中验证过。

## 04 把所有内容拼起来发给模型

**这一步在做什么？** 发请求前，`assemble()`（组装）先收集当前会话能看到的文字、背景信息和工具说明。然后 `renderPrompt()`（整理成文本）按顺序排列文字、填好空位、去掉空内容，并用空行把各段连起来。

可以把流程记成：

**收集内容 → 按顺序排列 → 填空 → 去掉空段 → 合成一段文本**

**动手看看：** 点击“运行此阶段”，再打开“状态与数据”中的模型请求。请求里的 system 文本就是整理后的结果。场景使用固定回复的测试模型，不会连接真实模型；它验证普通对话这条路径，不代表重试、真实模型或中断恢复也在这里运行过。
