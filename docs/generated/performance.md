# 性能基线

记录于 2026-10-18，测试：`packages/trace/tests/performance.spec.ts`（Node 22，云端 Linux 容器）。数值随机器变化，测试只断言目标上限。

| 场景 | 结果 | 目标（02 §14） |
|---|---|---|
| 5,000 条小型记录、50 个实例，建立回放索引（每 100 条一个检查点） | 约 55 ms | — |
| 任意位置回放跳转 p50 | 约 0.17 ms | — |
| 任意位置回放跳转 p95 | 约 0.4–0.5 ms | < 200 ms |
| 5,000 条记录分 100 批增量建索引（实时运行的界面路径） | 约 35 ms | — |

界面为每个运行缓存一个回放索引，每批轨迹只归约新增记录；接收缓冲只维护连续前缀，单批工作量与批大小成正比。此前每批都重建索引，长运行下总耗时随记录数平方增长。

时间线列表按固定行高窗口化，只渲染可见行与少量缓冲行，轨迹长度不影响渲染量；回放位置变化时自动滚动到当前行。

## 浏览器交互

测试：`apps/explorer/e2e/interaction.spec.ts`（Playwright Chromium，构建后的静态界面）。从点击到 DOM 出现变化后的下一帧计时，不含测试进程的往返。

| 场景 | 结果 | 目标（02 §14） |
|---|---|---|
| 切换插件树图层（6 次） | 最大约 14 ms | 点击反馈 < 100 ms |
| 选中实例，检查器显示摘要（3 次） | 最大约 15 ms | 点击反馈 < 100 ms |
| 缩放后添加插件 | 视口变换不变 | 新增节点不重置视口 |

`fitView` 只在插件树首次挂载时生效；测试已验证，若插件树在组合变化时重新挂载，视口会被重置并使测试失败。
